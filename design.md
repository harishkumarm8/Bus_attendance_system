# Design system — Royal Grace

Use the installed frontend-design skill with the established college theme. Precision, clarity and restraint take priority over decorative complexity.

## Identity
Grace College of Engineering logo and name remain in the shared header. Do not restore the removed GracER mark or duplicate admin breadcrumb/user bar.

## Visual language
- Royal plum navigation, purple actions, restrained gold icon accents.
- Soft neutral canvas, white panels, gentle shadows, readable table headers.
- Manrope typography, consistent spacing, visible keyboard focus and responsive controls.
- Bootstrap Icons supplement text labels; never use icons as the only accessible label.
- At least 44px interactive targets, reduced-motion support and mobile table scrolling.

## Interaction
- Search updates after a typing pause; dropdown/date filters update on selection.
- Bus editor starts with one drop point and one staff selector; add/remove controls extend the lists.
- Student drop points follow the chosen bus. Active and inactive assignments remain editable.
- Show loading/error/empty states. Never use a style change to modify authentication, data or report semantics.

## PDF
Landscape A4, college heading, report date/filter, present/absent counts, repeated table headings and page numbering. PDF includes all filtered rows, not only the screen's current pagination page.
